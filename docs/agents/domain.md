# Domain Docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md`.
- Read any relevant ADRs in `docs/adr/`.

## Vocabulary

Use the canonical terms from `CONTEXT.md` in issue titles, ticket descriptions, tests, and implementation work. If a needed concept is not defined there, surface it for domain modeling rather than inventing a synonym.

## ADR conflicts

If work contradicts an existing ADR, call out the conflict explicitly instead of silently overriding it.
